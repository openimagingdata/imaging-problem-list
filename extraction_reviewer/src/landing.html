Extraction Review

Open a folder of extraction JSON files to review. For each finding, approve or flag it with a comment. You can also log findings the extractor missed. Progress is saved automatically in this browser. When you’re done, download a zip of review files to send back.

Drop extraction JSON files here
Or pick a folder / individual files. Paired .txt or .md files with the same basename (e.g. cxr001.json + cxr001.txt) are loaded as the source report.
